# brand

Matt Coward's "MC" monogram, served by GitHub Pages so other sites can link to it.

| File | Use |
| --- | --- |
| `mc-logo.svg` | Source artwork (vector). |
| `mc-logo.png` | 512×512 PNG. This is the Cloudflare Access login page logo. |
| `mc-logo-192.png` | 192×192 PNG for small placements. |

Live URL: https://mbcoward3.github.io/brand/mc-logo.png

Keep the file names stable: Cloudflare Zero Trust points at the PNG URL.
